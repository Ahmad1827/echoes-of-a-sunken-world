# Echoes of a Sunken World

A silhouette sword duel in a drowned world, built with Godot 4.7.

**Download:** grab `EchoesOfASunkenWorld.exe` from the [Releases](../../releases) page. It's a single file; just run it.

- `game/` holds the Godot project. Open it in Godot 4.7 and press F5. Controls, mechanics and the layout of the code are in [game/README.md](game/README.md).
- `index.html` is the first browser prototype.
